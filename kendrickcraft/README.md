# Kendrick Craft ✈️💻

Mod para Minecraft Java **1.21.1** con **NeoForge 21.1.248**.

Incluye coche y avión manejables, armas, una computadora interactiva que abre una página HTML local en el navegador, un minijuego de reflejos y bloques colocables para construir un aeropuerto.

## Controles
- Coche: clic derecho para subir; W/S acelera o retrocede; A/D gira.
- Avión: clic derecho para subir; W acelera y mira hacia donde quieres volar.
- Tren de aterrizaje: pulsa **G** mientras pilotas para mostrar u ocultar visualmente las ruedas.

## Computadora
Coloca el bloque **Computadora interactiva** y haz clic derecho. Crea el archivo `kendrickcraft-computer.html` en la carpeta del juego y lo abre en el navegador predeterminado. La página tiene una barra para abrir direcciones o buscar, accesos a Google, YouTube y Steam, y un minijuego para tocar objetivos.

## Bloques de aeropuerto
Pista de aterrizaje, calle de rodaje, panel de hangar, luz de aeropuerto y helipuerto. Se encuentran en la pestaña creativa Kendrick Craft y se colocan manualmente.
