# Kendrick Craft ✈️💻🛰️

Mod para Minecraft Java **1.21.1** con **NeoForge 21.1.248**.

Incluye coche, avión, armas, computadora interactiva, bloques de aeropuerto y un **mapa orbital** que se abre con **M**.

## Mapa orbital
- **Mi mundo:** mapa cenital coloreado a partir de los bloques reales de chunks cargados, con marcador de posición y zoom.
- **Tierra:** ilustración estilizada del planeta.
- Usa los botones de zoom y **Esc** para cerrar.

**Limitación:** las zonas no cargadas aparecen oscuras. Explora para cargar terreno. Esta versión no escanea automáticamente todos los chunks guardados ni conserva un atlas completo entre sesiones; la vista de Tierra es ilustrativa, no una fotografía satelital.

## Controles
- **M:** abrir mapa orbital.
- Coche: clic derecho para subir; W/S acelera o retrocede; A/D gira.
- Avión: clic derecho para subir; W acelera y mira hacia donde quieres volar.
- **G:** mostrar u ocultar visualmente las ruedas mientras pilotas.

## Computadora
Coloca el bloque Computadora interactiva y haz clic derecho. Crea el archivo kendrickcraft-computer.html en la carpeta del juego y lo abre en el navegador. Incluye barra de direcciones/búsqueda, accesos a Google, YouTube y Steam y un minijuego de reflejos.

## Bloques de aeropuerto
Pista de aterrizaje, calle de rodaje, panel de hangar, luz de aeropuerto y helipuerto, disponibles en la pestaña creativa Kendrick Craft.
