# Kendrick Craft (NeoForge 1.21.1)
Compatible con el modpack XDDD (Minecraft 1.21.1, NeoForge 21.1.248). No depende de ningún otro mod.

## Compilar
1. Instala JDK 21. Abre la carpeta en IntelliJ IDEA (importa Gradle) o ejecuta `gradle wrapper` y luego `./gradlew build`.
2. El .jar queda en `build/libs/kendrickcraft-1.0.0.jar`. Cópialo a la carpeta `mods` del pack.

## Uso
- `/go to sol`  → al Sol. Supervivencia/aventura: mueres. Creativo: normal, como en la Tierra.
- `/go to tierra` → mundo Tierra continuo (10 000 x 5 000 bloques por mitad; al salir por un borde apareces en el opuesto).
- Pestaña creativa "Kendrick Craft": armas, munición, coche y avión.
- Coche: clic derecho para subir, W/S acelera, A/D gira. Avión: W acelera, con velocidad alta despega y vuela donde mires.
  Golpea un vehículo para recogerlo.

## Modrinth
Sube el .jar como Mod, Loader: NeoForge, Game version: 1.21.1.
